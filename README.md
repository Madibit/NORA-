## 1️⃣ Telegram Aggregation Layer

## 2️⃣ Intelligent Telegram Bot  
🤖 Bot: @NORA_ir_Bot  

ربات پروژه به عنوان لایه توزیع Push عمل می‌کند.

قابلیت‌ها:
- شناسایی خودکار فرمت‌های مختلف (vmess / vless / trojan / ss و …)  
- دسته‌بندی و تفکیک بر اساس پروتکل  
- ارسال خودکار آخرین کانفیگ‌ها برای کاربران فعال  
- کاهش نیاز به بررسی دستی کانال  
- آماده‌به‌کار بودن پیش از وقوع اختلال  

در سناریو بحران، کافی است ربات از قبل فعال شده باشد.

## 3️⃣ Internal Resilient Host Layer  

یک هاست داخلی مقاوم که حتی در سناریو «ملی شدن اینترنت» نیز در دسترس باقی می‌ماند.

نقش این لایه:
- اجرای اسکریپت‌های تجمیع به‌صورت خودکار  
- بروزرسانی و انتشار مداوم کانفیگ‌ها و پروکسی‌ها  
- مدیریت صف انتشار داده‌ها  
- حفظ پایداری سیستم در زمان اختلال بین‌المللی  

ویژگی‌ها:
- استقرار در زیرساخت داخلی با دسترسی پایدار  
- طراحی برای حداقل وابستگی به سرویس‌های خارجی  
- امکان بازیابی سریع در صورت قطعی بخشی از شبکه  
- معماری ماژولار برای توسعه‌پذیری آینده  

این لایه تضمین می‌کند که حتی در شرایط محدودیت سراسری، فرآیند تجمیع و انتشار متوقف نشود.
